# Home Component

Modern React implementation of the static `home-1-49.html` using the Ocean Professional theme.

- Reusable pieces: Header, SearchBar, CategoryChips, FoodGrid, FoodCard, FloatingActionButton, BottomNav.
- Theme tokens are defined in `src/theme.css`.
- Legacy tokens from `assets/common.css` are still imported to maintain parity with source assets.
- Images are imported from `assets/figmaimages`.

To modify seed items, edit the `items` array in `Home.jsx`.
